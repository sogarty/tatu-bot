# Развёртывание Tattoo Bot на Render

Эта инструкция — для людей без опыта программирования. Следуйте шагам по порядку.

---

## 📋 Что у нас есть

- **backend** — FastAPI + Telegram-бот (эта папка `deploy/`)
- **frontend** — Mini App для Telegram (папка `web/` из `TATU_deploy` или `TATU`)

---

## ⚠️ Важное про хостинг

Render **убрал бесплатный тариф** в 2024 году. Минимальная стоимость — **$7/мес** за Web Service.

Бесплатные альтернативы с поддержкой Python:
- **[PythonAnywhere](https://www.pythonanywhere.com)** — бесплатный тариф, но только для HTTPS-серверов через их домен
- **[Fly.io](https://fly.io)** — бесплатный пакет до $5/мес (включая 3 инстанса)
- **[Railway](https://railway.app)** — $5 кредитов при регистрации, потом платно

Если всё равно хотите Render — создавайте **Starter** план ($7/мес).

## ШАГ 1. GitHub-репозиторий для backend

1. Зайдите на [github.com](https://github.com) и войдите в аккаунт.
2. Нажмите зелёную кнопку **New** (или **Create a new repository**).
3. Придумайте имя репозиторию, например `tattoo-bot`.
4. Поставьте галочку **Private** (чтобы код был виден только вам).
5. Нажмите **Create repository**.
6. Нажмите **Add file** → **Upload files**.
7. Перетащите в окно браузера **ВСЕ файлы и папки** из папки проекта (`deploy/`):
   - `app/` (папку целиком)
   - `alembic/` (папку целиком)
   - `tests/`
   - `web/`
   - `.gitignore`
   - `alembic.ini`
   - `README_DEPLOY.md`
   - `requirements.txt`
   - **НЕ загружайте**: `.env`, `*.db`, `__pycache__`, `venv`, `logs`
8. Прокрутите вниз и нажмите **Commit changes**.

✅ Готово! Backend загружен на GitHub.

## ШАГ 2. GitHub-репозиторий для Mini App (frontend)

1. Создайте **отдельный** новый репозиторий, например `tattoo-bot-web`.
2. Загрузите в него **только 3 файла** из `web/`:
   - `app.js`
   - `index.html`
   - `style.css`
3. Нажмите **Commit changes**.

Теперь включите GitHub Pages:
4. В этом репозитории перейдите: **Settings** → **Pages** (в меню слева).
5. В разделе **Build and deployment** → **Source** выберите **Deploy from a branch**.
6. Branch: **main** (или **master**), Folder: **/ (root)**.
7. Нажмите **Save**.
8. Подождите 1–2 минуты, обновите страницу. Вы увидите ссылку вида `https://ВАШ-НИК.github.io/tattoo-bot-web/`.
9. **Скопируйте эту ссылку** — она понадобится в Шаге 4.

## ШАГ 3. Создание сервиса на Render

1. Зайдите на [dashboard.render.com](https://dashboard.render.com) и войдите.
2. Нажмите **New** → **Public Web Service** (да, «Public» — это просто тип сервиса, он может быть приватным).
3. Выберите ваш GitHub-репозиторий `tattoo-bot` (backend).
4. Заполните форму:

| Поле | Что написать |
|------|-------------|
| **Name** | любое, например `tattoo-bot-api` |
| **Region** | ближайший к вам (например **European Moscow** или **Oregon**) |
| **Branch** | `main` |
| **Root Directory** | оставьте пустым |
| **Runtime** | **Python 3** |
| **Build Command** | `pip install -r requirements.txt` |
| **Start Command** | `uvicorn app.main:app --host 0.0.0.0 --port $PORT` |
| **Python Version** | **3.12** |

5. Нажмите **Create Web Service**.
6. Сервис начнёт деплой. Это займёт 3–5 минут. Сначала будет красная полоса «Building»…

## ШАГ 4. Переменные окружения (секреты)

**НИКОГДА не записывайте токены в код!** Они хранятся только в настройках Render.

В настройках вашего сервиса на Render найдите секцию **Environment** и добавьте переменные:

| Переменная | Значение | Как получить |
|-----------|---------|-------------|
| `BOT_TOKEN` | ваш токен бота | от [BotFather](https://t.me/BotFather) |
| `MASTER_TG_ID` | ваш числовой ID в Telegram | от [@userinfobot](https://t.me/userinfobot) |
| `MODE` | `webhook` | просто напишите это слово |
| `WEBHOOK_BASE_URL` | пока оставьте пустым (заполните после первого деплоя) | адрес появится, когда сервис заработает |
| `WEBHOOK_SECRET` | длинная случайная строка | `python -c "import secrets; print(secrets.token_urlsafe(32))"` — или сгенерируйте на [randomkeygen.com](https://randomkeygen.com) |
| `ALLOWED_ORIGINS` | адрес вашего Mini App (из Шага 2) | вида `https://ваш-ник.github.io/tattoo-bot-web/` |
| `WEBAPP_URL` | тот же адрес Mini App | что и ALLOWED_ORIGINS |
| `DATABASE_URL` | пока оставьте пустым (SQLite создастся автоматически) | — |
| `ENVIRONMENT` | `production` | просто напишите это слово |

**Важный порядок:**
1. Сначала создайте сервис (Шаг 3).
2. Дождитесь, пока он заработает (станет зелёным).
3. Скопируйте адрес сервиса (вверху страницы, вида `https://tattoo-bot-api-xxxx.onrender.com`).
4. Вставьте его в переменную `WEBHOOK_BASE_URL`.
5. Перезапустите сервис: **Dashboard** → **Manual Deploy** → **Deploy latest commit**.

## ШАГ 6. Мониторинг (чтобы сервис не засыпал)

Web Service на Render засыпает, если нет запросов. Чтобы он был всегда на связи:

1. Зайдите на [uptimerobot.com](https://uptimerobot.com) и создайте бесплатный аккаунт.
2. Нажмите **Add Monitor** → **HTTP**.
3. Вставьте адрес: `https://ВАШ-СЕРВИС.onrender.com/health`
4. Интервал: **5 минут**.
5. Нажмите **Save**.

Теперь UptimeRobot будет стучаться на ваш сервис каждые 5 минут, и он не будет «засыпать».

## ⚠️ Ограничения тарифа Render

| Ограничение | Что это значит |
|------------|----------------|
| **Минимальная цена** | $7/мес (бесплатного тарифа больше нет) |
| **Нет постоянного диска** | Файлы, созданные во время работы (например, SQLite-база), **НЕ сохраняются** после перезапуска |
| **Минимальные ресурсы** | 512 МБ RAM, ~0.5 vCPU — хватает для небольшого бота |
| **Пропускная способность** | 5 ГБ/мес бесплатно |

### 💾 База данных — что делать?

SQLite-база на Render **не сохраняется** между перезапусками. Для продакшена нужно подключить внешнюю базу данных.

**Самый простой бесплатный вариант: [Neon](https://neon.tech)** (PostgreSQL Serverless).

Переход на Neon:
1. Создайте бесплатный проект на [neon.tech](https://neon.tech).
2. Скопируйте connection string (вида `postgresql://...`).
3. Вставьте его в переменную окружения `DATABASE_URL` на Render.
4. База будет храниться в облаке и не пропадёт.
